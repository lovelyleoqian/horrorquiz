怎么导入我自己的题库？支持什么格式？

点「导入我的题库」，把 Word / PDF / 笔记里的题粘进去就行，支持三种写法，可混用：

① 逗号或竖线分隔，一行一题：题干|A选项|B选项|C选项|D选项|B|解析（可省）
② 标准多行格式：
1. 题干文字
A. 选项一
B. 选项二 …
答案：B
解析：为什么
③ JSON 数组：[{"q":"题干","o":["A","B","C","D"],"a":1,"ex":"解析"}]（a 是正确项下标，从 0 开始）

也支持直接把 .txt / .md / .json 文件拖进导入框，或点「选择文件」。导入的题库存在浏览器本地，下次打开还在。

答错的题会自动进「怨念错题本」，可以单独开一轮只刷错题，也能导出 JSON 备份。
